ABOUT

Goldbach's conjecture says every even integer greater than 2 is the sum of two primes. It is unproven, and was checked up to 4×1018 by Oliveira e Silva, Herzog and Pardi. This network extends that check to 5×1018, in the open, with anyone's GPU. More about the conjecture: Dimostriamo Goldbach.

This project is inspired by their paper, Empirical verification of the even Goldbach conjecture and computation of prime gaps up to 4·1018 (Math. Comp. 83, 2014). Its figures, recomputed live from this verification: the live paper.

Each even n gets a pair n = p + q with p a small prime and q confirmed prime by a complete sieve; anything left over is settled by deterministic Miller-Rabin. Browsers run the same algorithm as the native B580 verifier (WebGPU + WebAssembly), and a browser slice only counts when a second device reproduces it bit for bit. Phones run a lighter mode (keep the screen on). The server itself verifies with its spare CPU. Raw board: /board (try: curl goldbach.net01.io/board).
